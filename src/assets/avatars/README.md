Tips
- Square, 512 x 512 px is plenty (they are shown between 40 and 100 px). Face centred with some room around the head: they are cropped to a circle.
- WebP at quality ~80 keeps each one under ~40 KB.
- They are fictional people: use generated faces, not photos of real people (the page says "fictional data").
- If a name has no file, the illustrated avatar is used, so you can add them one by one.
